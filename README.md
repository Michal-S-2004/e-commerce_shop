# E-commerce Shop Database

## About

This project was created to improve my SQL and database design skills by building a relational database for an e-commerce store.

The goal is to design the database from scratch, create the schema in PostgreSQL, populate it with sample data, and solve real business problems using SQL queries.

During the project I will focus on database modeling, writing efficient SQL queries, query optimization, and creating reports based on the stored data.
